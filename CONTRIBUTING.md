## Pull Requests
If you want to do actual development on PWEngine, pull requests are the best place to start. 
Notice: If you use agent to developing your program. Read `AGENT.md` firstly.

### The C++ Style
Namespace/Class Style: BigCamel
Function Style: smallCamel
Variable Style: snack_case
Constant Style: snack_case

The namespace is only two level:
`PWEngine::ModulesName`

Add ThirdParty:
Only header-only library will be add in third-party folder.
If the library is not a header-only library. Try to compile local and use static linked.
Use dynamic linked is limited. If you want to do. Tell me firstly.

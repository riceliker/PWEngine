# Contributing

The commercial companies such as Microsoft, Google etc which have a tactics. Support the Open Source Project. Master the right to speak in program. Remover community code or use CLA to Close Source Project.
We will never became the next Qt!
We should not destroy this program again. So we reject all contribute from commercial companies.

## Pull Requests
If you want to do actual development on PWEngine, pull requests are the best place to start. 
In the first, your code will store a EXT module. If we think it is useful, it will be store in core.
Notice: If some code write by agent is allow. But we reject vibe coding.

### The C++ Style
Namespace/Class Style: PascalCase
Function Style: camelCase
Variable Style: snack_case
Constant Style: Snack_Case

The namespace is only two level:
`PWEngine::ModulesName`

Add ThirdParty:
Only header-only library will be add in third-party folder.
If the library is not a header-only library. Try to compile local and use static linked.
Use dynamic linked is limited. If you want to do. Tell me firstly.
